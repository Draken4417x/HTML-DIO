O HTML e sua criação

HTML (HyperText Markup Language) é a linguagem de marcação usada para estruturar páginas da web. Criado por Tim Berners-Lee no início dos anos 90, o HTML surgiu como uma forma de conectar documentos através de hiperlinks, permitindo a navegação na internet. Seu principal objetivo é organizar e apresentar o conteúdo na web, definindo elementos como títulos, parágrafos, imagens e links. Ele trabalha em conjunto com CSS (para estilização) e JavaScript (para interatividade), formando a base da web moderna.

Estrutura do HTML

A estrutura básica do HTML consiste em elementos essenciais para a criação de uma página web. O documento começa com , indicando o uso do HTML5. Em seguida, a tag html envolve todo o conteúdo, enquanto head contém informações como título e metadados. O body abriga o conteúdo visível, como textos, imagens e links. Essa estrutura define a organização da página e permite sua exibição correta nos navegadores.

Tags HTML

Algumas Tags HTML comuns:

  • title – Define o título da aba do navegador.
  • meta – Fornece metadados sobre a página, como charset e viewport.
  • h1 a h6 – Criam títulos e subtítulos de diferentes tamanhos.
  • p – Define um parágrafo de texto.
  • a href="URL" – Cria um link para outra página ou recurso.
  • img src="imagem.jpg" alt="Descrição" – Insere uma imagem.
  • ul e ol – Criam listas não ordenadas (ul) e ordenadas (ol).
  • input type="text" – Cria um campo de entrada de texto para o usuário.
  • button – Cria um botão interativo.
  • div – Agrupa elementos para organização e estilização da página.

Listas em HTML

As listas em HTML são usadas para organizar e apresentar elementos de forma ordenada ou não ordenada. Existem três tipos principais de listas:

Listas não ordenadas (ul): Apresentam itens sem uma sequência numérica, usando marcadores (geralmente pontos).
Listas ordenadas (ol): Apresentam itens em uma sequência numérica ou alfabética.
Listas de definição (dl): São usadas para listar termos e suas respectivas definições, utilizando dt para o termo e dd para a definição.
Essas listas ajudam a organizar o conteúdo, melhorando a legibilidade e a estrutura da página
